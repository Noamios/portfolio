# 🍽️ My Recipe Finder

A beautiful recipe search app built with React.

## Features
- 🔍 Search recipes from TheMealDB API
- ⭐ Save favorite recipes
- 📱 Fully responsive design
- 💾 Data persists with localStorage
- 📋 View detailed ingredients and instructions

## Technologies
- React
- JavaScript (ES6+)
- Fetch API
- CSS3
- localStorage

## Live Demo
[Visit the app](https://your-app.netlify.app)

## Getting Started

### Installation
```bash
npm install
npm start
```

### Build
```bash
npm run build
```
